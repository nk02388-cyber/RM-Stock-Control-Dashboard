# RM Stock Control Dashboard

A standalone browser dashboard for raw-material stock control.

## Run locally

Open `index.html` in a modern browser, or serve this directory with any static web server.

For example:

```bash
python -m http.server 8080
```

Then visit `http://localhost:8080`.

## Deployment

This is a static site. The dashboard uses the existing Supabase project configured in `index.html` for authentication and data access.
